# TREMENDOUS!

**MAKE EVERY TOKEN TREMENDOUS!**

Tremendous is a Donald Trump-inspired parody skill for coding agents. You give it a job. It does the job with simple words, BIG CAPS, rude jabs at bad code, long detours, and a victory lap so large the original bug may need a map. Explanations! Code reviews! Release notes! A VERY SMALL FIX WITH A VERY LARGE PRESS CONFERENCE!

Look, your agent can say, “Remove the unused variable.” Fine. A useful answer. But what about the variable's terrible record? Sitting there, taking up space, doing NOTHING! What about the beautiful line of code that no longer has to share a file with this weak little freeloader? Tremendous gives that story the absurd amount of room it never needed. THE VARIABLE IS GONE. THE SPEECH HAS JUST BEGUN!

You get the answer, the drama, the side trip, the return from the side trip, and another reminder that the answer was a GREAT DEAL. The words are plain. The tone is loud. The bad loop is having a very rough day. And you, folks, you still need to know how to install the thing. Let's get you the thing!

## INSTALL IT. GIVE YOUR AGENT A BIGGER MOUTH!

You need **Node.js with `npx`** and a coding agent that supports skills. Open your terminal and run the command below. One command! A SMALL COMMAND WITH ENORMOUS PLANS FOR YOUR NEXT ANSWER!

```sh
npx skills add preacherxp/tremendous --skill tremendous
```

Follow the installer prompts and choose your agent. That's where the skill goes. A very clear deal: you pick the agent, it gets the voice, and the next bad idea you ask it to explain may find itself called a TOTAL CLOWN SHOW. (With reasons! The reasons still matter!)

Want Tremendous available across projects for **both Codex and Claude Code**? Use this global install command. Two agents, the same loud skill, a BEAUTIFUL EXPANSION OF THE WORD BUSINESS!

```sh
npx skills add preacherxp/tremendous --skill tremendous --agent codex claude-code --global
```

Already downloaded this project? You have the files! GOOD FILES! Open a terminal in the folder containing `SKILL.md` and install from that folder:

```sh
npx skills add . --skill tremendous
```

Choose the install route that fits where you are. You do not need to run all three commands. We're here to repeat the POINT, folks, not make you install the same damn skill three times. ONE ROUTE. GET IT INSTALLED. THEN GIVE IT A JOB!

## ASK FOR TREMENDOUS. BRING A REAL TASK!

Tell your agent to use the skill by name and say what you want done. A bug to explain, code to review, a release note that has all the life of a wet receipt. GIVE IT THE JOB! The performance needs a subject, and your slow function has been waiting far too long for its very public review.

```text
Use the tremendous skill to explain why this function is slow.
```

In Codex, invoke it with **`$tremendous`**. Keep the dollar sign and add your request. A very important dollar sign! It belongs right there, at the front, where a dollar sign with a job should be.

```text
$tremendous review this code and fix the bug
$tremendous explain why one app is enough for this project
$tremendous rewrite this release note
```

Give it the code or text it needs, just as you would for an ordinary request. The voice is BIG. It does not make a missing file appear by yelling at it. If you want a review of a function, provide the function or point your agent to it. REAL INPUT. REAL WORK. ABSURD AMOUNTS OF COMMENTARY!

And think about that release note for a moment. “Fixed a crash.” Three words, and the crash gets to leave quietly! Tremendous can give the fix a whole rescue story. The crash was bad, the fix is good, the app gets another chance to work, and somehow we are still talking about it. But back to your request, because YOU SET THE JOB. The speech serves the job, even when the speech takes the long way home!

## ONE SETTING. MAXIMUM!

There is one preset: **MAXIMUM**. No little dial. No mild sauce. You asked for the big voice, and the big voice has brought repetition, CAPS, plain words, odd asides, occasional swearing, and a deep personal dislike of a badly planned rewrite. A TREMENDOUS AMOUNT TO SAY ABOUT A VERY ORDINARY PROBLEM!

And the SIGNATURE MOVES, folks! The bug gets a nickname that tells you what's wrong with it, like the Leakin' Listener. Dead code gets a loud “YOU'RE FIRED!”, but only once it's really gone. Green tests become a rally crowd, counted from the real run. And sometimes the database walks up, tears in its eyes, and says, “Sir, thank you.” A DATABASE! Obviously fictional. Obviously TREMENDOUS!

Expect answers much longer than usual. Even a tiny question can turn into several paragraphs, with examples, complaints about the bug, a detour into how the mess happened, and another proud look at the fix. These are style instructions, not a promise that every model will produce the same length or land every joke. MODELS VARY! A boast is not a benchmark!

Here's the deal: **MORE WORDS MEAN MORE OUTPUT TOKENS**. If your service bills for those tokens, longer replies can cost more. You get the performance; your token budget gets the bill. Read that part! A VERY IMPORTANT PART OF THE DEAL! This is for when the extra words are the fun, and you want the answer to arrive with a parade that could have ended three streets ago.

## YOU STILL HAVE CONTROL!

Want the voice inside a word limit? Put the limit in your request. YOUR LIMIT COUNTS! The skill follows explicit requests for short answers and exact formats, even when it has a beautiful tangent ready and nowhere to put it.

```text
$tremendous explain this bug in under 100 words
```

Need only JSON, only code, or a command you can copy? Say so. A speech outside your JSON would break the deal. A TOTAL FORMAT DISASTER! The skill is instructed to keep exact outputs exact and fit any permitted style into the space you actually gave it.

Ready for your agent's usual voice? Ask it to stop using Tremendous. You can request it for one task or for a session, and later change your mind. YOU HAVE CONTROL! The speech does not get to keep the microphone after you ask for it back.

```text
Stop using Tremendous and return to your usual style.
```

## A SMALL TASTE OF A VERY LARGE ANSWER!

An ordinary answer says, “Keep it as one script.” A fair answer! Five words, home before lunch. Here's a short Tremendous-style excerpt from the same idea. SHORT EXCERPT, folks. The full performance has more places to go!

> Two hundred lines. TWO PEOPLE! And now this “smart” plan needs SIX SERVERS? What a damn mess! You had a function call, a BEAUTIFUL FUNCTION CALL, and it went from one part of the app to the other part, which was right there, folks, RIGHT THERE!
>
> Now you have slow calls, failed calls, and a meeting to ask whose call failed. A TOTAL CLOWN SHOW! (And for WHAT?) The work used to happen in one place. You could read it, run it, fix it. Now your little app has a whole travel schedule just to get the same answer!
>
> Keep the script. Keep the parts clear. Measure the real slow part before you build a whole new system around a guess. ONE APP, CLEAR PARTS, LESS CRAP! A beautiful deal for the two people who have to keep this thing alive. Thank you for your attention to this matter!

That's the voice: an actual point, a complaint with a subject, simple words, and a win announced several times. THE POINT STILL HAS TO BE RIGHT! Calling six servers a clown show is only useful when the work really can fit in one app. The joke does not get to pick the facts.

## BIG VOICE. THE WORK STILL HAS TO WORK!

Tremendous changes the prose. Code, commands, names, and structured data must stay exact. A variable does not need a campaign slogan. Your shell command does not need extra exclamation marks. KEEP THE WORK USABLE! The agent should finish the task and put the drama in the explanation.

Facts and test results must stay honest too. A failed test is a FAILED TEST! You cannot call it a “beautiful success” and hope the red output gets shy. If something has not been measured, the agent should say so. If a fix is only proposed, it should say that too. REAL RESULTS FIRST. THE VICTORY LAP HAS TO EARN ITS SHOES!

The jabs go at bugs, bad code, and bad plans. You're on the same team as the agent. That dumb loop can take a hit; the skill calls for no protected-group slurs, threats, or made-up claims about real people. WE ARE HERE TO ROAST THE BUG! The bug had a bad plan, and now we can talk about why.
